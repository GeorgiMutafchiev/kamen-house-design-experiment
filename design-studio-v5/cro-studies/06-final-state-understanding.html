Task comparison

User intent
After checking details, a visitor wants to know whether anything was sent and what, if anything, happens next.
Required information
Validation result; explicit non-transmission; no reservation; information retention/copy guidance; truthful next step.
Decision and click count
Current: 1 check click after valid entry. Proposed: 1 check click. This study tests semantic clarity, not fewer clicks or a live commercial completion.
Trust
Never call this a submitted enquiry, successful reservation, or confirmation. The local preview has no recipient or booking engine.
Friction to investigate
The component state is named `success`, although the user outcome is only valid local input. A visitor could miss the no-send caveat if status language is skimmed.
Mobile behavior
Place the outcome immediately after the button in reading order, announce it accessibly, and keep the non-transmission message visible without a modal.
Limitations
This storyboard does not copy data, transmit a message, or create a booking. Comprehension requires a real task test.
