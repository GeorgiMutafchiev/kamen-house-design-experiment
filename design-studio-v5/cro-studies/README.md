# Six isolated CRO task-flow studies

These are low fidelity, rendered HTML storyboards for the six tasks in `../cro-research/LOCAL_TASK_FLOW_AUDIT.md`. Open each `.html` file in a browser. Each contrasts the implemented path with a shortest clear path **to test**, states modelled decision/click counts, and names trust, friction, mobile, source, and evidence limits. They are not user tests, external funnel audits, homepage designs, or conversion results. KAMEN HOUSE is a fictional concept; the enquiry preview transmits nothing and reserves no room.

## Interpretation boundary

The “current” column is derived from local route/component source, not observed visitor behavior. The “shortest clear path” column is a hypothesis for later usability work, not a coded change or a validated minimum. Click counts are modelled from route topology. The network tunnel returned systemic 503 during this research, so no complete external hospitality booking flow has been verified. See `../cro-research/MISSING_FUNNEL_EVIDENCE.md`.
