# Atomic pattern catalog

The event log stores machine-readable patterns with reference IDs, observations, polarity, and confidence. These files explain what to inspect in each area and later hold concise synthesis notes. An empty category is an honest research gap. Do not fill it from model memory.

For each accepted pattern, record the observed page and viewport, the abstract relation, a KAMEN-specific hypothesis, what must not be copied, and its reference IDs. `research/research-coverage.json` counts only usable patterns attached to researched non-holdout references.
