# Independent rendered evaluation

No direction may be certified by its creator. Use real desktop (1440px), laptop (1024px), and mobile (390px) screenshots. Each review record identifies a creator and different reviewer, role, verdict, and concrete visible evidence.

The intended jury roles are art direction, typography, hospitality credibility, UX, mobile, originality, coherence, and holdout comparison. A candidate's internal filter passes only with at least four independent review records, including a holdout review, and no failing verdict. This filter does not approve production integration. The human owner alone may record `approved`, `partially_approved`, or `rejected` for a rendered direction.

The holdout researcher sees the full ledger. Concept makers receive only `export-concept-brief`, which strips holdout identities and patterns. Because agents in a shared workspace could still inspect repository files, this is procedural isolation unless separate filesystem permissions are provided. Do not claim cryptographic secrecy.
